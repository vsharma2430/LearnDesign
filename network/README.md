# Networking Learning Path

This directory turns the outline in [`../topics/network.md`](../topics/network.md) into a self-paced course. Each numbered module groups related networking concepts in a `lessons.md` file.

## Modules

1. [Network Foundations](01-network-foundations/lessons.md)
2. [IP Addressing and Routing](02-ip-addressing-and-routing/lessons.md)
3. [Transport Layer](03-transport-layer/lessons.md)
4. [DNS](04-dns/lessons.md)
5. [HTTP and HTTPS](05-http-and-https/lessons.md)
6. [Modern Web Communication](06-modern-web-communication/lessons.md)
7. [Networking for System Design](07-networking-for-system-design/lessons.md)
8. [Interview Preparation](08-interview-preparation/lessons.md)

## Suggested study loop

1. Work through modules in order, building up from network foundations.
2. Trace how a request moves through the network and explain each layer.
3. Compare protocols and design choices by their reliability, latency, and trade-offs.
4. Revisit the interview topics and explain concepts without relying on notes.
