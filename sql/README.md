## Suggested study loop

1. Learn relational modeling and transaction behavior before tuning queries.
2. Practice writing queries on small example datasets and inspect edge cases.
3. Use execution plans to connect SQL constructs to indexes and database work.
4. Revisit interview patterns and explain correctness as well as performance.
