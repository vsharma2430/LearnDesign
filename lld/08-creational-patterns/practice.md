# Creational Patterns — Practice

1. A game creates one of several enemy types from level data. Compare a factory method, registry, and direct conditional.
2. A UI toolkit supports matching buttons, menus, and dialogs for different platforms. Explain why Abstract Factory might help.
3. Design a builder for a notification with required recipient and optional title, body, and attachment. Where do validation rules run?
4. A prototype has a mutable list of children. What must copying do to avoid accidental shared mutation?
5. A connection pool is proposed to improve performance. Which lifecycle and measurement questions must be answered first?
6. Explain one testing or concurrency concern with a global singleton.
