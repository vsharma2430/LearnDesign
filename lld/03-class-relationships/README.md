# 3. Class Relationships

Model how types connect to each other without pretending the coupling is stronger than it really is.

## Learning sequence

1. Read the [lessons](lessons.md) and focus on ownership, lifetime, and substitutability.
2. Use the relationship checklist to choose the right model before writing code.
3. Work through the [practice exercises](practice.md) and explain why each relationship fits.
4. Review the [mock interview Q&A](mock.md) to practice answering in interview language.

## Topics

Association · aggregation · composition · dependency · realization / implementation · generalization / inheritance

**Goal:** Communicate ownership, usage, and substitutability between types without overstating the coupling.

**Ready when:** You can explain whether an object owns another, merely refers to it, or calls it temporarily, and whether a subtype truly satisfies the parent contract.
