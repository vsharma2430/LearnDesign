# 2. OOP Fundamentals

Learn to model concepts as objects with clear contracts, protected invariants, and purposeful behavior.

## Learning sequence

1. Read the [lessons](lessons.md), following the examples from state and encapsulation through domain models.
2. Answer the lesson's quick self-check without looking back.
3. Complete the [practice exercises](practice.md) in order; sketching and explaining your decisions is more valuable than syntax.
4. Revisit the common pitfalls and revise any design that exposes state or adds abstractions without a clear purpose.

## Topics

Classes and objects · encapsulation and abstraction · interfaces, inheritance, and polymorphism · construction and lifecycle · enums and state transitions · immutability and equality · entities, value objects, DTOs, and domain models · rich and anemic models · composition

**Ready when:** You can name an object's invariants, choose operations that protect them, distinguish identity from value equality, and explain why an abstraction or inheritance relationship fits a requirement.
