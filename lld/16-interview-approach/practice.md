# LLD Interview Approach — Practice

For each prompt, spend a few minutes clarifying requirements, sketch a model, and walk through one scenario:

1. Design a parking lot with multiple vehicle sizes and a pricing policy.
2. Design a library checkout flow with holds, due dates, and unavailable copies.
3. Design an elevator controller. Clarify what is in scope before modeling scheduling.
4. Design a board game engine that supports turns and legal moves.

After each attempt, review:

- Did you clarify behavior before choosing classes?
- Are object responsibilities and ownership clear?
- Does one normal and one failure path preserve invariants?
- Did any pattern solve a real problem, or only add indirection?
- Could you incorporate a new requirement with a focused change?
