# Behavioral Patterns — Practice

1. A checkout can calculate discounts using one of several policies. Use Strategy and identify who selects the policy.
2. A document editor supports undo. Compare Command history with Memento snapshots.
3. A request passes through authentication, validation, and logging. Model the order using Chain of Responsibility and define failure behavior.
4. A media player has stopped, playing, and paused states. List valid events and transitions before choosing a State implementation.
5. A chat room coordinates participants. Explain how Mediator can reduce coupling and how it can become too central.
6. A stable expression tree needs multiple operations such as printing and evaluation. Is Visitor a fit? What if new expression types are frequent?
