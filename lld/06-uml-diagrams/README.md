# 6. UML Diagrams

**Goal:** Select a diagram that answers a design question and use notation clearly enough to support discussion.

**Study:** [Lesson notes](lessons.md) → [Practice](practice.md) → [Mock interview Q&A](mock.md)

**Ready when:** You can draw a small class model and a sequence of behavior, then explain any omitted detail.

## Topics

- Class diagram
- Use case diagram
- Sequence diagram
- Activity diagram
- Object diagram
- State diagram
- Component diagram

UML is not a single diagram; it is a family of views. Choose the one that helps answer the current design question without drawing more detail than the team needs.
