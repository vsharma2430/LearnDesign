# UML Diagrams — Practice

1. Draw a class diagram for a library member borrowing a copy of a book. Mark which objects have independent identity.
2. Draw a sequence diagram for placing an order with inventory validation and payment authorization. Include one failure path.
3. Model a traffic light lifecycle using a state diagram. What makes an invalid transition invalid?
4. Choose between an activity diagram and sequence diagram for a multi-step approval workflow. Explain what each would reveal.
5. With five minutes left in an interview, choose one diagram for a turn-based game feature and justify what you omit.
