# Structural Patterns — Practice

1. A vendor SDK returns a different payment API than your domain expects. Sketch an Adapter boundary.
2. A document contains paragraphs and nested sections that can all render. Which pattern fits? Where should child ordering live?
3. Add timing and retry behavior around a service call. Compare a Decorator with editing the service directly.
4. A media library has many files that share large metadata but have distinct playback positions. Identify flyweight and per-object state.
5. A complex subsystem requires seven setup calls. Design a Facade method and explain what it should not absorb.
6. A proxy checks authorization. How will it preserve the subject's observable contract and report denial?
