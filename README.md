# System Design Learning Repository

This repository is a structured learning path for system design and software engineering topics.

## Contents

- [hld.md](./hld.md) — High-Level Design roadmap and topic checklist
- [lld.md](./lld.md) — Low-Level Design roadmap and topic checklist
- [lld/](./lld) — LLD module-based learning materials
- [hld/](./hld) — HLD study folder

## Learning flow

1. Start with the HLD roadmap to understand the big-picture system concepts.
2. Move into the LLD roadmap to refine object-oriented design and implementation patterns.
3. Use the numbered modules in the `lld/` folder for deeper, structured practice.
4. Combine theory with mock interviews, design tradeoff analysis, and practical implementation exercises.

## Goals

- Build a strong foundation in architecture, distributed systems, and scalability
- Understand common interview patterns for HLD and LLD rounds
- Practice tradeoff-based reasoning instead of memorizing answers
